# FolioWrite

**FolioWrite** คือโปรแกรมจัดการและพิมพ์เอกสารแบบ **Local-First Web App + PWA** ที่ออกแบบให้ใช้งานได้บนทุกอุปกรณ์ (คอมพิวเตอร์, แท็บเล็ต, โทรศัพท์มือถือ) โดยไม่ต้องสมัครสมาชิก ข้อมูลถูกจัดเก็บในเครื่องผ่าน `IndexedDB` พร้อมรองรับการนำเข้าและส่งออกไฟล์มาตรฐาน `.docx` และ **PDF**

## ความสามารถหลัก

- **Rich Text Editor ครบครัน:** หัวข้อ (`H1`–`H3`), ฟอนต์ภาษาไทยและสากล (`Sarabun`, `IBM Plex Sans Thai`, `Inter`, `Source Serif 4`, `JetBrains Mono`), ขนาดอักษร, สีข้อความ, ไฮไลต์, การจัดหน้าย่อหน้า, รายการลำดับ, เช็กลิสต์, ตาราง และรูปภาพ
- **รองรับทุกอุปกรณ์ (Cross-Device Responsive + PWA):**
  - แถบเครื่องมือแบบ Tabbed Ribbon บนจอคอมพิวเตอร์
  - โหมดพอดีจอมือถือ (**Mobile Reflow**) และแถบเครื่องมือด่วนติดขอบล่างสำหรับหน้าจอสัมผัส
  - รองรับการติดตั้งลงหน้าจอหลัก (Installable PWA) และทำงานแบบออฟไลน์
- **นำเข้าและส่งออกไฟล์มาตรฐาน:**
  - **Import:** `.docx`, `.html`, `.txt`, `.md`
  - **Export:** `.docx` (ECMA-376 OpenXML), พิมพ์ / บันทึกเป็น **PDF** ขนาด A4 / US Letter, `.html`, `.md`, `.txt`
- **จัดการเอกสารในเครื่อง:** แม่แบบเอกสาร 5 รูปแบบ, โฟลเดอร์แยกสี, ปักหมุด, ค้นหาข้อความในเอกสาร, ถังขยะกู้คืนได้, ประวัติเวอร์ชันย้อนหลัง (Snapshots) และระบบสำรอง/กู้คืนข้อมูลทั้งหมด (`.json`)

## การรันโปรเจกต์ในเครื่อง

```bash
npm install
npm run dev
```

สร้างไฟล์สำหรับใช้งานจริง (Production + PWA Service Worker):

```bash
npm run build
npm run preview
```

รันชุดทดสอบอัตโนมัติ (Playwright E2E):

```bash
npx playwright test
```
